Quadra 0.43.3 offers to move you to the Rust version of Quadra. Nothing else changes from 0.43.2.

- **The offer:** Quadra has been rewritten in Rust, and the rewrite is in early testing (0.50 alpha). It runs Roblox through Rosemary only. When you open the settings window, Quadra asks once whether you want to try it, and you can answer "Not now" or "Don't ask again". Settings → Environment → Quadra → Rust version offers it again at any time. It is never offered on Darling or in the Flatpak.
- **Three ways to install it:** the AppImage (one file in `~/.local/bin` that updates itself), the Flatpak (installed for your user; it needs Flatpak, and VR may not work in its sandbox), or a build on your computer (clones the source and compiles it in a terminal window; it needs Rust 1.85 or newer, git, a C compiler and the GTK 4.18 and libadwaita 1.7 development packages, and it does not update itself).
- **Safety:** the AppImage and the Flatpak are downloaded from the rewrite's GitHub releases and checked against that release's `SHA256SUMS` before anything is installed. This Quadra stays installed, keeps working, and is only closed once the new one is installed. Your settings and Roblox sign-in are not carried over.
- Everything in the 0.43.2 and earlier notes still applies.

Validation: the 496 unit tests pass, and the offer dialog was checked in a headless GTK session; the other UI fixtures still pass except `m2vk_settings_ui`, which already failed on main. The generated install scripts were syntax-checked and tested with awkward paths, and the download and checksum code against a simulated network. The real flows were not run: downloading an AppImage or Flatpak from GitHub, the terminal hand-off, a native build, or the switch to the new Quadra. They need a Rust release that publishes `SHA256SUMS`, which is 0.50.0-alpha.2 or newer.

Fully close and reopen Quadra after updating. Studio is not in the Flatpak. OpenGL remains the default for the game on Darling; VR requires OpenGL or Vulkan/Zink. Native packages include the matching Metal host and framework. Install `.pkg.tar.zst` on Arch derivatives, `.deb` on Ubuntu 24.04+/Debian 13+, the binary `.rpm` on current Fedora, or the Flatpak with `flatpak install --user quadrahq-0.43.3-x86_64.flatpak` (it uses Flathub's GNOME 51 runtime). Darling/CiderDarling downloads remain separate. Source archives, build recipes and `SHA256SUMS` are attached.
